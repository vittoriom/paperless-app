Core Capabilities

Engineered for Privacy & Organization

No heavyweight Docker containers, no remote databases, and no cloud subscriptions. Paperless Desktop gives you native Mac performance and complete data ownership.

⚡

Instant Full-Text Search

Embedded SQLite with FTS5 tokenization and custom Rust AST query compiler. Filter by boolean logic, dates, prefixes (tag:, type:, correspondent:, ext:), and custom metadata.

🌐

On-Device Neural Translation

Integrated with macOS native Translation.framework via Swift. Ingest contracts or receipts in German, Italian, or French and search them seamlessly in English without cloud APIs.

📥

Automated Inbox & Folder Mirroring

Monitors your inbox directory in the background. Ingests files into date hierarchies or preserves your existing folder tree as mirrored virtual folders.

🔍

Duplicate Detection & Relinking

Combines cryptographic SHA-256 matching with lexical token similarity. Automatically relinks moved or renamed documents preserving tags and custom fields.

💽

Decoupled Storage & External Drives

Store your SQLite index locally while keeping gigabytes of documents on external drives, network shares, or secondary disks. Degrades gracefully offline.

🤖

CLI & Model Context Protocol (MCP)

Native command-line interface and built-in MCP server. Connect local AI tools like Claude Desktop or Cursor to query, summarize, and cross-reference your archive securely.

Quick Setup

macOS Installation Guide

Follow these simple steps to install and run Paperless Desktop on Apple Silicon or Intel Macs.

1

1. Download the Disk Image (.dmg)

Download the latest universal macOS DMG bundle directly from our GitHub Releases page.

2

2. Drag to Applications Folder

Mount the DMG and drag Paperless Desktop into your /Applications directory.

3

3. Allow First Launch (macOS Gatekeeper)

As an independently compiled open-source binary, right-click the app in Finder and choose Open, or run this one-line terminal command:

xattr -cr "/Applications/Paperless Desktop.app"
4

4. Initialize Your Vault

Launch the app and select any local folder or existing document directory. Paperless instantly sets up indexing without modifying your originals.

Got Questions?

Frequently Asked Questions

Everything you need to know about storage formats, backups, translation, and privacy.

Where are my actual document files stored?

−
Your files remain regular, standard files in whatever folder you choose on disk! Paperless never locks your files inside proprietary databases or hidden containers. It organizes documents into clean date hierarchies (e.g. documents/YYYY/MM/) or preserves your existing folder tree while keeping an embedded SQLite index (.paperless/paperless.db) for instant querying.

Does Paperless modify or alter my original documents?

+
Never. Paperless strictly adheres to non-destructive ingestion. Extracted full-text layers, tags, translation caches, and custom metadata are stored in the SQLite database alongside the original file. Your PDFs and original files are left untouched.

How does on-device translation work without the internet?

+
On macOS 13+, Paperless leverages Apple's native Translation.framework executed in a companion Swift helper. All neural machine translation happens on the Apple Neural Engine directly on your Mac, ensuring zero bytes of your sensitive invoices or contracts ever hit a remote server.

Can I store my documents on an external SSD or network drive?

+
Yes! Paperless features Decoupled External Storage. You can place your document archive and inbox on a NAS network share or external drive, while keeping the SQLite database on your fast internal SSD. If the drive is unplugged, Paperless remains fully searchable and warns you gracefully.

How does the Model Context Protocol (MCP) server work?

+
Paperless comes with a built-in MCP server that exposes tools like search_documents, get_document_text, and list_tags. You can plug it into Claude Desktop or Cursor in seconds to ask questions like: 'Summarize all invoices from Apple in 2025'.

How do I backup my archive?

+
Because everything resides in standard directories on disk, backups are trivial. Apple Time Machine, rsync, restic, or your preferred backup tool will seamlessly back up both your files and the .paperless/ database without needing to dump Docker containers or databases.
